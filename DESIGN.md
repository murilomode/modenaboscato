# Portfolio design

Audience: recruiters for HR, people coordination and administrative operations.
Use clear first-person English, short paragraphs and factual examples. Do not invent direct reports, budgets, qualifications or Australian HR experience.

Visual language: warm off-white (#f7f5f0), navy (#132a3a), restrained teal (#287271). Georgia for headings, system sans-serif for body. Existing portrait, generous but purposeful spacing, simple rules and rectangular links. No decorative dashboards, gradients or scroll reveals. Content and navigation must remain available without JavaScript.

Prefer native semantic HTML. Visible keyboard focus, meaningful links, useful 404, reduced-motion support, readable mobile pages and no hidden mobile navigation. Validate at 390px and desktop width, with keyboard and JavaScript disabled.

References reviewed: https://vercel.com/design/guidelines ; https://github.com/Leonxlnx/taste-skill ; https://github.com/VoltAgent/awesome-design-md . User preference for restrained motion overrides the gpt-taste skill's animation requirements. This is a project-specific direction, not a copied brand design.


## Specific reference checked on the second pass
Source: https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/notion/DESIGN.md
Borrowed principles: a documented spacing scale, restrained hairline dividers, a clear body/caption hierarchy and separate filled/outlined action styles. Project choices remain Georgia/system sans, navy/teal and off-white. The reference's purple pills, pastel feature cards, Inter-based font and decorative hero are deliberately excluded to honour the user's screenshots. This is selective adaptation, not full adoption of the Notion brand.

## Audit boundary
Vercel guidelines have been checked against source code. Runtime keyboard behaviour, computed contrast, viewport overflow and Lighthouse remain unverified until a browser audit succeeds. No design skill has been installed; gpt-taste was read and its conflicting motion requirements were not applied.

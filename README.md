# Murilo Boscato: HR, Management & Operations

Static professional portfolio at https://modenaboscato.com/ . HTML, CSS and JavaScript; no framework, package installation or build step.

## Preview
Open index.html in a browser, or run `python -m http.server 8000` from this directory.

## Pages
- index.html: experience, work examples, résumé and contact.
- work-sample.html: payroll preparation and workflow case.
- samples.html: HR and operations examples.
- 404.html: recovery page for unknown URLs.

assets/ contains the portrait, favicon and existing public career documents. The general CV URL is retained for compatibility; the linked résumé remains HR-focused.

See DESIGN.md for visual rules, docs/CONTENT-MAINTENANCE.md for factual checks and docs/DEPLOYMENT.md for GitHub Pages setup. robots.txt, sitemap.xml and llms.txt are served from the root. llms.txt is optional and does not guarantee search visibility.

No analytics, contact backend or cookie banner is introduced. Contact uses email links.

The unused output_gemini directory (303 generated images) was removed. Other legacy files are still awaiting cleanup. Earlier versions remain in Git history; history was not rewritten.
